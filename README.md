
# Neural Network

A neural network built to play video games autonomously through reinforcement learning.
It processes game state data (visual and numerical) to make real-time decisions aimed at maximising performance.

The model continually improves by learning from its experiences — refining its strategies, adapting to new scenarios, and optimising actions to achieve higher scores and complete in-game objectives efficiently.

🧠 Key Features

Learns directly from gameplay data

Uses reinforcement learning to optimise decisions

Adapts dynamically to new game challenges

Supports real-time input and output for live environments
